Cómo funciona

Binario oficial, sin recompilar nada

Un launcher nativo Android (Bionic) invoca el cargador glibc de Termux para ejecutar el binario oficial de Freebuff. Sin emuladores ni configuraciones manuales.

Launcher nativo

Un launcher compilado en C para Android/Bionic se instala como freebuff en $PREFIX/bin.

Capa glibc de Termux

Usa el cargador ld-linux-aarch64.so.1 de la capa glibc oficial para lanzar el binario real.

Descarga multi-fuente

Binario desde vendor oficial → espejo propio → caché local. Todo con verificación de integridad.

FAQ

Preguntas frecuentes

Resolvemos las dudas más comunes sobre la instalación de Freebuff en Termux.

Freebuff es la terminal de IA oficial de Codebuff: un agente de programación que trabaja dentro de tu terminal con los modelos Freebuff. Este proyecto permite instalarlo de forma nativa en Termux para Android ARM64, sin emuladores ni proot.

No. Un launcher nativo compilado para Android (Bionic) invoca el cargador glibc de Termux (ld-linux-aarch64.so.1) para ejecutar el binario oficial de Freebuff. No se requieren root, proot, máquinas virtuales ni Cloud Shell.

La versión de Termux en Google Play está desactualizada y abandonada. La versión oficial se mantiene en F-Droid, que es la única compatible con este instalador.

El binario oficial de Freebuff es un build glibc, incompatible directo con Android/Bionic. El instalador compila un launcher en C (Bionic) que ejecuta el cargador glibc de Termux (ld-linux-aarch64.so.1) para lanzar freebuff de forma nativa y transparente.

El instalador solo funciona en dispositivos ARM64 (aarch64). Verifica tu arquitectura con uname -m; debe mostrar aarch64.

Vuelve a ejecutar bash install.sh en el repositorio clonado para descargar la última versión. El instalador descarga desde vendor oficial → espejo propio → caché local, siempre con verificación de integridad.

Ejecuta bash install.sh --uninstall en el repositorio clonado. Esto elimina el launcher de $PREFIX/bin y el binario real, y ofrece eliminar la configuración. Los respaldos quedan en ~/backups/freebuff.

Ejecuta freebuff en Termux y escribe /login dentro de la interfaz. Se abre el flujo oficial de Codebuff para iniciar sesión con tu cuenta o usar una API key.

El instalador usa descarga multi-fuente por prioridad: vendor oficial (npm freebuff), espejo propio (GitHub Releases de este repo) y caché local como último recurso. Si una fuente cae, pasa automáticamente a la siguiente.
